# Oliver Co — Website UI kit

A high-fidelity recreation of the Oliver Co. London marketing storefront, expressed through the design-system tokens in `../../colors_and_type.css`.

> No codebase or Figma was provided. This kit is a **reference recreation** of the brand's stated visual language and the public storefront pattern (Shopify) — not a 1:1 port. Treat components as cosmetic; functionality is mocked.

## Surfaces included
- **Header** — editorial top navigation with mono eyebrow strip
- **Hero** — full-bleed photographic plate with floating annotations
- **ProductGrid** — three-column collection grid with archival labels
- **MaterialStudy** — large specimen panel with spec key/value table
- **Footer** — quiet manifest-style links + newsletter

## How to view
Open `index.html` — it stitches the components into a single editorial homepage.
